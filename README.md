# 🎓 Telegram-бот для онлайн-обучения с оплатой через ЮKassa

Готовый асинхронный Telegram-бот на Python 3.12+ (**aiogram 3.x**) для регистрации учеников на онлайн-курс и приёма оплаты через платежную систему **ЮKassa** с автоматической выдачей доступа к материалам/каналу и панелью администратора.

---

## 🌟 Основные возможности

1. **Пошаговая регистрация учеников (FSM):**
   - Сбор ФИО (для сертификата и базы).
   - Сбор номера телефона (по кнопке контакта или вручную).
   - Сбор адреса электронной почты (для отправки чека по 54-ФЗ).
2. **Оплата через ЮKassa (Telegram Payments):**
   - Нативные счета прямо внутри Telegram.
   - Поддержка карт МИР, Visa, Mastercard, СБП, SberPay и др.
   - Передача данных для фискализации чека.
   - Поддержка как тестовых платежей, так и боевых.
3. **Автоматическая выдача доступа:**
   - Сразу после подтверждения оплаты бот поздравляет ученика и выдает персональную ссылку-приглашение в закрытый канал курса.
4. **Уведомления администраторам:**
   - Мгновенное оповещение администраторов в Telegram о каждой успешной оплате (ФИО, телефон, email, никнейм, сумма, тариф).
5. **Панель администратора (`/admin`):**
   - Онлайн-статистика: количество перешедших в бота, заполнивших анкету, совершивших оплату и общая выручка.
   - Экспорт базы учеников в красиво оформленный файл **Excel (.xlsx)** с полными контактными данными и ID транзакций.
6. **База данных:**
   - SQLite на базе асинхронного SQLAlchemy 2.0 (`aiosqlite`) — не требует отдельного сервера БД, легко переносится и бэкапится.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Рекомендуется создать виртуальное окружение:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация на Windows:
venv\Scripts\activate

# Активация на Linux/macOS:
source venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка конфигурации (`.env`)

Скопируйте файл `.env.example` в `.env` (или отредактируйте созданный `.env`):

```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
PAYMENT_PROVIDER_TOKEN=381764678:TEST:12345
ADMIN_IDS=123456789
CHANNEL_INVITE_LINK=https://t.me/+AbCdEfGhIjK12345

```

## 🔑 Инструкция по получению токенов

### 1. Как получить `BOT_TOKEN`:
1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например, `Курс Кати`).
4. Введите юзернейм бота, заканчивающийся на `bot` (например, `KatyaCourse_bot`).
5. Скопируйте полученный HTTP API токен и вставьте в `BOT_TOKEN` в `.env`.

### 2. Как подключить ЮKassa и получить `PAYMENT_PROVIDER_TOKEN`:
1. В диалоге с [@BotFather](https://t.me/BotFather) отправьте команду `/mybots`.
2. Выберите вашего созданного бота.
3. Нажмите **Payments**.
4. В списке провайдеров найдите и выберите **ЮKassa (YooKassa)**.
5. Для тестирования выберите **Connect YooKassa Test** (для реальных оплат — **Connect YooKassa Live**).
6. BotFather перенаправит вас на страницу авторизации ЮKassa. Войдите в личный кабинет ЮKassa и подтвердите подключение магазина.
7. После подтверждения BotFather пришлет вам сообщение с токеном провайдера (для теста он начинается с цифр и слова `:TEST:`, например `381764678:TEST:12345`).
8. Скопируйте этот токен в `PAYMENT_PROVIDER_TOKEN` в файле `.env`.

### 3. Как узнать свой `ADMIN_IDS`:
1. Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram.
2. Он пришлет ваш цифровой `Id` (например, `123456789`).
3. Вставьте его в `ADMIN_IDS`. Если администраторов несколько, укажите их через запятую: `123456789,987654321`.

### 4. Ссылка на закрытый канал `CHANNEL_INVITE_LINK`:
- Создайте закрытый канал/чат для обучения.
- В настройках канала перейдите в **Тип канала -> Пригласительные ссылки -> Создать новую ссылку**.
- Скопируйте ссылку и укажите её в параметре `CHANNEL_INVITE_LINK`.

## ▶️ Запуск бота

Запустите бота командой:

```bash
python main.py
```

После запуска бот автоматически создаст базу данных `bot_database.db`, добавит тарифы по умолчанию и начнет принимать сообщения.

---

## 🛠 Управление тарифами

По умолчанию в файле [bot/database/db.py](file:///bot/database/db.py) настроены 3 базовых тарифа:
- **Тариф «Базовый»** — 4 900 ₽
- **Тариф «С куратором»** — 9 900 ₽
- **Тариф «VIP / Наставничество»** — 24 900 ₽

Вы можете изменить названия, описания или цены прямо в переменной `DEFAULT_TARIFFS` в [bot/database/db.py](file:///bot/database/db.py) перед первым запуском, либо редактировать таблицу `tariffs` в базе данных.
