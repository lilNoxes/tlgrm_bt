# 📋 Инструкция по запуску и настройке бота для онлайн-курса

Эта памятка составлена для быстрого запуска бота, подключения платежей и ежедневной работы организатора курса.

---

## ⚙️ Шаг 1. Заполнение файла настроек .env

В папке с ботом находится файл .env (если его нет, скопируйте .env.example и переименуйте в .env).
Откройте его в любом редакторе и укажите следующие параметры:

```env
# 1. Токен вашего бота (получить в @BotFather)
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# 2. Платежный ключ ЮKassa (получить в @BotFather -> Payments)
PAYMENT_PROVIDER_TOKEN=390540030:LIVE:12345

# 3. Telegram ID администраторов через запятую (узнать свой ID можно в @userinfobot)
ADMIN_IDS=123456789,987654321

# 4. ID закрытого канала курса (для создания персональных одноразовых ссылок)
CHANNEL_ID=-1001234567890

# 5. Запасная ссылка-приглашение на канал
CHANNEL_INVITE_LINK=https://t.me/+AbCdEfGhIjK12345

# 6. Юзернейм организатора или куратора для связи (без знака @)
SUPPORT_USERNAME=Katya_Manager

# 7. Название базы данных (оставьте по умолчанию)
DB_NAME=bot_database.db
```

## 🔑 Шаг 2. Как получить токены (пошагово за 2 минуты)

### 1. Токен бота (`BOT_TOKEN`):
1. Откройте официального бота [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Введите название курса (например, *Онлайн-курс Екатерины*).
4. Введите юзернейм бота на английском, оканчивающийся на `bot` (например, *Katya_Course_bot*).
5. Скопируйте полученный HTTP API Token и вставьте в `BOT_TOKEN`.

### 2. Подключение ЮKassa (PAYMENT_PROVIDER_TOKEN):
1. В диалоге с [@BotFather](https://t.me/BotFather) отправьте команду /mybots и выберите вашего бота.
2. Нажмите **Bot Settings** ➔ **Payments**.
3. Найдите в списке **YooKassa (ЮKassa)**:
   - Для боевых оплат выберите **Connect YooKassa Live**.
   - Для тестирования без списания денег выберите **Connect YooKassa Test**.
4. BotFather откроет защищенную страницу авторизации ЮKassa. Войдите в личный кабинет ЮKassa и подтвердите привязку магазина.
5. BotFather пришлет сообщение с готовым токеном платежей (начинается с цифр и :LIVE: или :TEST:).
6. Скопируйте его и вставьте в PAYMENT_PROVIDER_TOKEN.

### 3. Ваш Telegram ID (ADMIN_IDS):
1. Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram.
2. Скопируйте число из строчки Id: (например, 207682205) и вставьте в ADMIN_IDS.
3. Если администраторов несколько, укажите их через запятую: 207682205,123456789.

## 🔒 Шаг 3. Настройка закрытого канала курса

Чтобы бот мог автоматически выдавать каждому ученику **персональную одноразовую ссылку** (которую нельзя переслать третьим лицам):
1. Откройте ваш закрытый канал с уроками курса.
2. Зайдите в **Управление каналом** ➔ **Администраторы** ➔ **Добавить администратора**.
3. Найдите вашего бота по юзернейму и добавьте в канал.
4. **Обязательно включите право:** **«Пригласительные ссылки» (Invite Users via Links)** и нажмите Сохранить.
5. Укажите цифровой ID канала в CHANNEL_ID в файле .env (например, -1002345678901).
   *(Чтобы узнать ID канала, перешлите любой пост из него боту @userinfobot или @JsonDumpBot).*

## 🚀 Шаг 4. Запуск на сервере (Хостинг Linux)

1. Клонируйте проект или загрузите файлы на сервер:
   ```bash
   git clone https://github.com/lilNoxes/tlgrm_bt.git
   cd tlgrm_bt
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл автозапуска службы `/etc/systemd/system/tgbot.service`:
   ```ini
   [Unit]
   Description=Telegram Bot Course
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/root/tlgrm_bt
   ExecStart=/usr/bin/python3 /root/tlgrm_bt/main.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
4. Запустите службу одной командой:
   ```bash
   systemctl daemon-reload
   systemctl enable --now tgbot
   ```
5. Проверить статус работы бота:
   ```bash
   systemctl status tgbot
   ```

## 👑 Шаг 5. Как пользоваться панелью администратора

Для вызова панели управления отправьте боту команду:
👉 **/admin**

Вам будут доступны все инструменты управления курсом:

1. **📊 Обновить статистику:**
   - Показывает число регистраций, сколько учеников оплатили, сколько думают (лиды) и общую сумму полученной выручки в рублях.
2. **📥 Полный отчёт (все вкладки в 1 файле):**
   - Скачивает сводный Excel-файл (.xlsx) с тремя вкладками:
     - 🟢 **Оплатившие курс:** ФИО, телефон, email, выбранный тариф, сумма, дата оплаты, ID платежа ЮKassa.
     - 🟡 **Лиды без оплаты:** ученики, которые указали контакты, но ещё не оплатили (база для персонального дожима).
     - 👥 **Все пользователи:** общий список всех, кто когда-либо запускал бота.
3. **🔍 Найти ученика / Управление доступом (CRM):**
   - Если ученик перевёл деньги на карту, оплатил по СБП или по счёту организации:
     - Нажмите «Найти ученика» и введите его телефон, @username, ID или имя.
     - Откроется карточка ученика с кнопкой **«🟢 Выдать доступ вручную (Оплатил)»**.
     - Выберите тариф — бот **мгновенно поздравит ученика в Telegram и пришлёт ему персональную ссылку на канал курса**!
   - Если потребовалось вернуть деньги — нажмите **«🔴 Отозвать доступ к курсу»**.
4. **📢 Сделать рассылку по базе:**
   - Позволяет отправить анонс или напоминание с любым текстом, картинкой или видео:
     - *Только лидам без оплаты* (предложить скидку, напомнить о старте).
     - *Только оплатившим ученикам* (ссылка на вебинар, расписание, оргмоменты).
     - *Всем пользователям бота* (общие новости).
   - Рассылка полностью защищена от спам-фильтров Telegram и снабжена живым прогресс-баром.

## 🧪 Шаг 6. Тестовая оплата перед запуском

Чтобы безопасно проверить работу ЮKassa и выдачу доступа:
1. Убедитесь, что ваш Telegram ID указан в `ADMIN_IDS` в файле `.env`.
2. В боте нажмите кнопку меню **«🎓 Оплатить обучение»** — вам как администратору сразу будет доступна кнопка **«🧪 Тестовая оплата (1 руб)»** (обычные ученики её не видят, для них отображается только «Оплатить 2399 руб»).
3. Также тестовый счёт можно вызвать в любой момент секретной командой: **/test_pay**
4. Проведите оплату 1 рубля: бот сразу выдаст персональную ссылку в закрытый канал курса, а в ЮKassa сформируется чек.
